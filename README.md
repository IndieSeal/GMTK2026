# GMTK2026

This game was a submission for <a href=https://itch.io/jam/gmtk-jam-2026>GMTK 2026</a>.<br>
You can check it out here: <a href=https://indie-seal.itch.io/lumina-folly>Lumina Folly</a>.<br><br>

There's been a few rumors about missing people, all coming from this one place... <br>
Welcome to <b>Lumina Folly</b>, and to the <b>Wayland Manor</b>.
<br><br>
You're an explorer and wanted to take a look at what's been a growing rumor, you enter the abandoned Manor, realizing you're stuck there, you'll have to beat the Monster's creatures and avoid the monster to escape the haunter Manor.
